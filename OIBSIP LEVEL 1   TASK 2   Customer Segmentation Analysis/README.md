# Project 1 - EDA on Retail Sales Data

## Objective
The objective of this project is to perform Exploratory Data Analysis (EDA)
on retail sales data and identify useful patterns and trends.

## Dataset
The dataset contains retail transaction information such as:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price
- Total Amount

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Steps
1. Load the dataset
2. Clean the data
3. Check missing values
4. Remove duplicate records
5. Perform statistical analysis
6. Create visualizations
7. Identify important trends

## Results
The analysis helped identify sales trends, customer behavior,
popular product categories, and other useful insights.
