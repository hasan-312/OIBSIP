# 👥 Project 3 — Customer Segmentation Analysis

**Track:** Data Analytics  
**Level:** Level 2  
**Task:** Customer Segmentation Analysis

### 📌 Description

This project uses **RFM Analysis and K-Means Clustering** to divide customers into meaningful groups based on their purchasing behaviour.

### 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- K-Means Clustering
- StandardScaler
- Matplotlib
- Seaborn
- Jupyter Notebook

### ✨ Analysis Performed

- Dataset inspection
- Data cleaning
- Missing value handling
- RFM analysis
- Recency calculation
- Frequency calculation
- Monetary value calculation
- Data standardization
- Elbow Method
- K-Means clustering
- Cluster visualization
- Customer segment profiling
- Marketing recommendations

### 🎯 Customer Segments

The analysis identifies different customer groups such as:

- ⭐ VIP / Loyal Customers
- 🔄 Regular Customers
- ⚠️ At-Risk High Value Customers
- 💤 Low Engagement Customers

### 💡 Business Value

The segmentation helps businesses create targeted marketing strategies instead of treating every customer the same.

For example:

- VIP customers → loyalty rewards
- Regular customers → upselling and cross-selling
- At-risk customers → win-back campaigns
- Low-engagement customers → promotional offers
