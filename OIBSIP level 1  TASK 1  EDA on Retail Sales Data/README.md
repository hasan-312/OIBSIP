 📊 Project 1 — Exploratory Data Analysis on Retail Sales

**Track:** Data Analytics  
**Level:** Level 1  
**Task:** EDA on Retail Sales Data

### 📌 Description

This project performs Exploratory Data Analysis on retail sales data to identify sales patterns, customer behaviour, product performance, and actionable business insights.

### 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### ✨ Analysis Performed

- Dataset inspection
- Missing value analysis
- Descriptive statistics
- Monthly sales trends
- Quarterly sales trends
- Customer age analysis
- Gender distribution
- Top 10 products
- Revenue by product category
- Correlation heatmap
- Additional business visualization

### 📈 Key Outcomes

The analysis helps identify:

- Sales trends over time
- High-performing products
- Important customer demographics
- Revenue-generating categories
- Relationships between numerical variables
