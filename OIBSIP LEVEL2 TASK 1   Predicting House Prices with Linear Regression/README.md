# 🏠 Project 3 — Predicting House Prices with Linear Regression

**Track:** Data Analytics  
**Level:** Level 2  
**Task:** Task 1 — Predicting House Prices with Linear Regression

### 📌 Description

This project uses **Linear Regression** to predict house prices based on selected property features. The project demonstrates how machine learning can be used to understand relationships between property characteristics and house prices.

### 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### ✨ Analysis Performed

- Loaded and inspected the housing dataset
- Checked data types and missing values
- Performed data cleaning
- Selected relevant features
- Split data into training and testing sets
- Built a Linear Regression model
- Trained the model using training data
- Generated house price predictions
- Compared actual vs predicted prices
- Evaluated model performance

### 📊 Model Evaluation

The model was evaluated using common regression metrics:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

### 📈 Visualizations

The project includes:

- Actual vs Predicted House Prices
- Feature relationships
- Correlation analysis
- Regression results

### 💡 Business Value

The model can help estimate property prices based on available property features. Such predictions can support:

- 🏠 Property valuation
- 💰 Pricing decisions
- 📊 Real-estate market analysis
- 📈 Investment decisions
